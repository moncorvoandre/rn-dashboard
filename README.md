# rn-dashboard
RN — Papelaria &amp; Bazar

O RN é um projeto de desenvolvimento de um sistema de gerenciamento de vendas e estoque, criado especialmente para a loja dos meus sogros.

Desenvolvido utilizando HTML, CSS e JavaScript, o sistema tem como objetivo facilitar a rotina da loja, oferecendo ferramentas para controle de produtos, gerenciamento de estoque, registro de vendas e acompanhamento de resultados.

Mais do que um projeto de programação, o RN representa um marco pessoal: é meu primeiro projeto publicado no GitHub e também uma oportunidade de transformar conhecimento em algo real, contribuindo diretamente com um negócio familiar.

Um projeto que une aprendizado, dedicação e propósito. 🤍
